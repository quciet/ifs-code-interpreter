Millennium Development Goal Display:

 

Within the International Futures System, we developed a display to track the Millennium Development Goals (MDG). For specific indicators, historical datasets are used to determine the 1990 base values and the 2015 target values for individual countries. When the dataset did not contain the base (1990) value for a specific country we estimated the value under reasonable assumptions using rules outlined below. For groups of countries (e.g., Sub-Saharan Africa or South Asia) aggregate values are determined using appropriate aggregation logic (e.g., population weighted average for percentage of people living with an income below $1/day) as described below.

 

MDG Goal 1, indicator 1 (percentage of people living below $/day, IncBelow1Dollar%) is used below for the purpose of explaining the logic of creating the MDG displays for various MDG indicators.

 

A. Rules for estimating the base (1990), latest (2002) and target(2015) values for any individual country

 

Base and current year values for any country is obtained from a regression line for that country, drawn using historical data points after 1985. Various imputations are used to make up for countries with no or very little data.  The overall procedure is given below:

 

  1. The base year (1990) and the latest year (2002) value for a country is interpolated from the best fit line drawn with the 1985 or later data points for that country. Whether an exact data point for the base (and the latest) year is available or not, regression estimates are always used for those two years.

 

  1. In case of a lack or shortage of data points, the following procedures are followed to fill in the gaps.

 

    1. For countries with less than 2 data points:

                                                               i.      First, a country cross-sectional function of IncBelow1Dollar%  versus GDP per capita at 2000 PPP (GDP2000PCPPP) is estimated for the year 2002 (or the most recent year after 1990 for which data series is available),

IncBelow1Dollar% = f(GDP2000PCPPP)

                                                             ii.      If data are not available for the (MDG) base year and/or the (time-series) latest year, the cross-sectional function mentioned above is used to calculate the base year and latest year values from the  GDP per capita at PPP for the country at the corresponding years

                                                            iii.      If only one data point (later than or on 1985) is available for any of these countries, that data is privileged. Function calculated base and current (latest year) values are shifted  by an amount equal to the distance of the only data value from its regressed value (i.e., only year value coming out of a linear regression with the 3 points – function calculated base year value, function calculated current year value and the only data value).

                                                           iv.      For countries, for which neither any of the GDP2000PCPPP data nor any poverty (IncBelow1Dollar%) data is available, only a IFs path will be drawn in the graph.

                                                             v.      If there is no data for GDP2000PCPPP and only one data point on poverty (IncBelow1Dollar%) data is available, an MDG goal path for the country will be drawn based on the available point, there won’t be any current path.

 

  1. Since the target 1 of goal 1, is to halve the proportion of poverty between 1990 and 2015, the target value for each individual country (for the income poverty target) is obtained by halving the base value as obtained above. A target value is calculated in a similar fashion for other goals and targets whenever appropriate. The target path is displayed in a graph (along with the current path) as outlined below.

 

 

B. Rules for group aggregation

 

IFs groups contain one or more country. The first step in calculating a group data point, is to deduce the base and current values for each group member using the same rules described (in A.) above (i.e., regression from a best fit line with minimum missing data estimated). The country values are then aggregated into group values with  appropriate weighting (e.g., population weighted average for percentage of population with income below 1 dollar). The group target value is obtained from the aggregated base value according to the particular MDG target.

 

Data values in Group Display:

Normally, the light blue bars in the group display are appropriately weighted averages of the member countries’ historical data or estimated values for the particular year. Hovering the mouse on the data bars will list the available data on the top left corner of the chart.

However, when the menu Display Options -> Use Estimates for Group History is not checked, the light blue bars in the group display are appropriately weighted averages of the member countries with available historical data only (for the particular year). Thus, they might not always reflect the real picture of the group in this case. Hovering the mouse on the data bars will list the available data on the top left corner of the chart.

 

 

 

C. Data Sources

 

Currently we have implemented the major indicators for poverty, hunger, education and child health goals.

 

On most of these indicators data were collected from the United Nations’ Statistic Division’s Millennium Indicator’s Database, (http://unstats.un.org/unsd/mi/default.asp)  and the World Bank’s World Development Indicators Database. Base, current and target values are calculated from  these data using rules described in A and B.

 

D. Graph Displays

 

Current Path: Current situation in the country is demonstrated by the brown line drawn by adding the base year (1990) point and the latest year point as obtained above.

 

MDG Goal Path: MDG goal path for the country is demonstrated by the pink line is drawn by adding the base year (1990) point and a target year (2015) point with the target value (calculated from base value as outlined in the MDG goals and targets).

 

IFs Paths: These are IFs (base case and scenario run) forecasts for the indicator.

 

Time Horizon: Country display starts at MDG base year 1990 or the foremost year for which data is available for the country, whichever comes first  and goes to the last year of IFs. Group display covers 1990 to last year of IFs.

 

E. Progress Calculation

 

For calculating the progress towards achieving a goal by a country (or group), rules outlined in the United Nation’s Human Development Report 2003 (Chapter titled Diagrams and Definitions) was used. The rule, in a nutshell, is to divide the rate of achievement from the MDG base year,1990 to the current year (the latest year for which data is available) by the required rate to achieve the goal within the MDG target year, 2015 and then categorizing the ratio as regress (<0), no progress(0), slow progress (<0.5), moderate progress (<1) and fast progress (>1).
