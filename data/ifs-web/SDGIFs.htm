Sustainable Development Goal Display:

 

Within the International Futures System, we developed a display to track the Sustainable Development Goals (SDG). For specific indicators, historical datasets are used to determine the 1990 base values and the 2030 target values for individual countries. When the dataset did not contain the base (1990) value for a specific country we estimated the value under reasonable assumptions using rules outlined below. For groups of countries (e.g., Sub-Saharan Africa or South Asia) aggregate values are determined using appropriate aggregation logic (e.g., population weighted average for percentage of people living with an income below $1/day) as described below.

 

SDG Goal 1, indicator 1 (percentage of people living below 1.25 $/day, in 2005 Dollars at Purchasing Power Parity) is used below for the purpose of explaining the logic of creating the SDG displays for various SDG indicators.

 

A. Rules for estimating the base (1990), latest (2014) and target (2030) values for any individual country

 

Base and latest year values for any country are estimated from a regression line for that country, drawn using historic data points after 1960 in the case where there’s no data for any of those points. Various inputs are used to make up for countries with no or very little data.  The overall procedure is given below:

 

  1. The base year (1990) and the latest year (2014) value for a country are estimated from the best fit line drawn with the 1985 or later data points for that country. When an exact data point for the base (and the latest) year is not available, regression estimates are used for any of the missing years.

 

  1. In case of a lack or shortage of data points, the following procedures are followed to fill in the gaps.

 

    1. For countries with less than 2 data points:

                                                              i.      First, a country cross-sectional function of IncBelow1.25Dollar%  versus GDP per capita at 2011 PPP (GDP2011PCPPP) is estimated for the latest year, 2014 (or the most recent year after 1990 for which data series is available).

IncBelow1.25Dollar% = f(GDP2011PCPPP)

                                                            ii.      If data are not available for the (SDG) base year and/or the (time-series) latest year, the cross-sectional function mentioned above is used to calculate the base year and latest year values from the  GDP per capita at PPP for the country at the corresponding years

                                                          iii.      If only one data point (later than or on 1985) is available for any of these countries, that data is privileged. Function calculated base and current (latest year) values are shifted by an amount equal to the distance of the only data value from its regressed value.

                                                          iv.      For countries, for which neither any of the GDP2011PCPPP data nor any poverty (IncBelow1.25Dollar%) data is available, only a IFs path will be drawn in the graph.

                                                            v.      If there is no data for GDP2000PCPPP and only one data point on poverty (IncBelow1Dollar%) data is available, an SDG goal path for the country will be drawn based on the available point, there won’t be any current path.

 

  1. Since the target 1 of goal 1, is to eradicate extreme poverty between 2015 and 2030, the target value for each individual country (for the income poverty target) is set at 3% for countries that have higher extreme poverty levels in 1990 and reduce by half for the rest. The target path is displayed in a graph (along with the current path) as outlined below.

 

 

B. Rules for group aggregation

 

IFs groups contain one or more country. The first step in calculating a group data point, is to deduce the base and current values for each group member using the same rules described (in A.) above (i.e., regression from a best fit line with minimum missing data estimated). The country values are then aggregated into group values with appropriate weighting (e.g., population weighted average for percentage of population with income below 1.25 dollar). The group target value is obtained from the aggregated base value according to the particular SDG target.

 

Data values in Group Display:

Normally, the light blue bars in the group display are appropriately weighted averages of the member countries’ historic data or estimated values for the particular year. Hovering the mouse on the data bars will list the available data on the top left corner of the chart.

However, when the menu Display Options -> Use Estimates for Group History is not checked, the light blue bars in the group display are appropriately weighted averages of the member countries with available historic data only (for the particular year). Thus, they might not always reflect the real picture of the group in this case. Hovering the mouse on the data bars will list the available data on the top left corner of the chart.

 

 

 

C. Data Sources

 

Currently we have implemented the major indicators for poverty, hunger, education, health, water and sanitation, energy, growth and employment, infrastructure, inequality, settlements, consumption, terrestrial ecosystems, peace and justice and global partnership goals.

 

On most of these indicators data were collected from the United Nations’ Statistic Division’s Millennium Indicator’s Database, (http://unstats.un.org/unsd/mi/default.asp), the World Bank’s World Development Indicators Database and various other sources, mostly international organizations. Base, current and target values are calculated from these data using rules described in A and B.

 

D. Graph Displays

 

Current Path: Current situation in the country is demonstrated by the brown line drawn by adding the base year (1990) point and the latest year point as obtained above.

 

Goal Path: The goal path for the country is demonstrated by the green line, and is drawn by joining the base year (1990) point and a target year (2030) point with the target value (calculated from base value as outlined in the SDG goals and targets).

 

IFs Paths: These are IFs (base case and scenario run) forecasts for the indicator.

 

Time Horizon: Country display starts at SDG base year 1990 or the foremost year for which data is available for the country, whichever comes first and goes to the last year of IFs. Group display covers 1990 to last year of IFs.
